# Changelog

## 0.2.0 — 2026-11-15

- Model-independent MCP tools for product search, identity/barcode lookup and alternatives.
- Local stdio, loopback HTTP, stateless bearer HTTP and persistent OAuth profiles.
- Generic HTTPS/desktop-loopback OAuth callbacks and callback-aware consent.
- Portable Windows/macOS/Linux installation, IP/SSH examples and configuration helper.
- Container profiles and managed-cloud deployment example using the platform PORT.
- Provider limits, explicit failures, provenance and bounded short-lived caching.
- Protocol, security, configuration and cross-platform automated tests.
